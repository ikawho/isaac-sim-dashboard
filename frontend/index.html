How the machine works

On the first start the GPU instance is set up and the Isaac Sim container is downloaded. Including the shader cache this often takes 20–30 minutes. Later starts are much faster.

Stop keeps the disk including the cache (you only pay for storage). Delete removes the machine completely; your files in My files are kept.

The stream is only reachable from the IP address you started the machine from. If your IP changes (different Wi-Fi, VPN), click “Allow my current IP”.

Your files appear in Isaac Sim under /workspace. Anything you save there is written back to My files every 2 minutes and when the machine stops.

Running machines are stopped automatically after 8 hours.
